# Validation artefacts

Templates and terms for the manual pilot (Stage 0). The pilot runs in spreadsheets, not in the
Guidr app. **Filled copies live in the private pilot folder, never in this repository.** Anything
committed here uses opaque references (`applicant_ref`, `org_ref`), never names or contact
details.

| File | What it is |
|---|---|
| `consent-form.md` | Terms each applicant agrees to before any data is collected (#52) |
| `data-handling.md` | Internal checklist: inventory, access, retention, deletion, breach (#52) |
| `ai-data-use.md` | Which services may see data, and the no-personal-data-to-models rule (#52) |

**No portfolio sheet is created before the applicant's consent is recorded.**

The pilot kit (offers, qualification screen, spreadsheet templates, week-by-week runbook) is
added by #51.
